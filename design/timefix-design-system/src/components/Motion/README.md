Motion atoms are the small moving parts every component shares: rolling numbers, swapping, morphing and soft-swapping words, a drawn tick, a spinner, a loading shimmer, rows that drop in and collapse, two icons in one slot, and AI work-in-progress text.

**Use them for**: `NumberRoll` on any count or stat that changes while you watch (inbox counts, booking totals, prices); `TextSwap` when a label changes state in place (Save → Saving → Saved, Booked → Cancelled); `TextMorph` when the two labels share letters (Copy link → Copied); `SoftText` for a value recomputed in place (a chart total after a period change, a price after a currency change); `SuccessCheck` as the confirmation inside buttons, menu items and toasts; `Spinner` inside a control whose action is in flight; `Skeleton` for the shape of content that is loading (never a page-wide spinner); `DropIn` around a new row in a list (comments, tasks, events) and `Collapse` for a row or section that closes to nothing; `IconSwap` for two icons in one slot (copy → check, eye → eye-off, play → pause); `ShimmerText` for work in progress ("Saving…") and `ThinkingLine` for an AI's cycling status lines.

**The consumer provides**: the value or label and, for `TextSwap`, a `swapKey` that changes with it; `TextMorph` takes `text`; `SoftText` takes the string as children and an `align` (`start`, `end`, `center`) so right-aligned figures keep their edge; `DropIn` takes `animate` (false for rows that were there on load), `Collapse` takes `open`, `IconSwap` takes `a`, `b` and `isB`, `ShimmerText` a string, `ThinkingLine` its `states` and a `hold` in ms.

**Interaction**: digits roll over `duration-slow` with `ease-out` and keep tabular width; words crossfade 4px vertically with a 2px blur over `duration-quick`; TextMorph keeps the shared letters still while the differing part cross-blurs over 180ms and its width eases over 240ms (transitions.dev 33); SoftText cross-blurs both values in one cell over 200ms while the width eases over 240ms (transitions.dev 34); the tick draws over `duration-base`; skeletons shimmer at 1.4s. DropIn opens the row's height from 0 while it rises 12px over `duration-fast`; Collapse closes 1fr → 0fr with a 2px blur (transitions.dev 21); IconSwap cross-fades through a 2px blur from 0.25 scale over `duration-fast` (09); ShimmerText sweeps a band across the glyphs every 2s (15); ThinkingLine rises the old line out and the next in, 2s apart (28). With reduced motion everything changes instantly.

**Replaces**: NumberPop, TextSwap, SuccessCheck, Spinner, Skeleton, Reveal, MotionDemos, TextMorph, SoftText, and the list, icon and AI motion bits that lived in AttributeField (DropIn, Collapse), Code (IconSwap) and AIAssist (ShimmerText, ThinkingLine).
