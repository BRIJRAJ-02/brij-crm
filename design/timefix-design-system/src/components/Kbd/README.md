A keycap shows the keyboard shortcut for an action, beside it in menus, buttons, tooltips, the sidebar and the command palette.

**The consumer provides** the combination as symbols (⌘, ⇧, ⌥, ↵, Esc), one keycap per combination. Inside an ink button or a tooltip it turns transparent with a faint edge. Shortcuts are hints: every action also has a visible control.

**Replaces**: Kbd.
