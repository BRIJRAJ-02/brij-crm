An object's attributes on its settings page: the ordered list, New attribute, and the dialog that creates and edits one attribute (the same surface as New object).

**Use it for**: Settings › Objects › Attributes, a grid's "+ Add attribute" and a column's "Edit attribute" (open `AttributeDialog` alone). **Don't use it for**: a record's values (AttributeField) or a relationship's two sides (RelationshipSettings).

**The consumer provides**: `objectName`, `objectPlural`, `attributes` (`SchemaAttribute`: the field system's Attribute plus `isRequired`, `isUnique`, `isSystem`, `numberFormat`, `defaultValue`, `options`, and `archived`, `computed` (formula, lookup, rollup), `relation` and `requiredWhen`), `onChange` with the whole new list, `valueCounts` for the type change warning, `usageOf` (what uses an attribute, said before archiving), `onNewSpecial` and `onEditSpecial` (relationship, formula, lookup and rollup open the consumer's own dialogs from a More kinds menu) and `pluralOf` (plurals for a relationship's type). `AttributeList`, `AttributeTypePicker` and `reorder` are exported for other screens.

**States**: rows with Required, Unique and System badges; dragging (the copy lifts under the pointer, a dashed gap where it will land, the others slide aside); a saved row washes once; archiving asks first (what uses it, then Archive), then a Callout with Undo; archived attributes list under the live ones with Restore. Dialog: create (type cards open, name focused), edit (current type, "Change type…"), type changed (warning Callout), system attribute (type locked), empty name (shake and hint), saving, saved.

**Interaction**: press a row or Enter to edit; drag by the grip (lib/drag.ts, one feel with the board), or Space on the grip, arrows, Space to drop, Esc to put it back. The dialog opens with the modal motion (06); Archive sits at the start of its actions, Cancel and Save at the end; the type cards, currency and number format settings open with the accordion (21); select and status types show the OptionsEditor; the default is the type's own AttributeField. Under Required, "Required when" picks another select or status field and one of its values (`siblings` gives the choices). The default value is one field: while it edits, its editor is the box.

**Replaces**: AttributeSettings.
