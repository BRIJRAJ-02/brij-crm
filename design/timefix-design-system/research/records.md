# Records / objects vs live (origin/main), 11 Nov
Table/views: spreadsheet range select + copy/paste (500, Undo) + clear range; column header menu (move, pin, hide, sort, filter, edit/archive attribute); "+" column (hidden columns, New attribute); footer "+ Calculate" per column (count, empty, sum, avg, min, max); group by any status/select with foldable tinted headers + total; board on any object (any status/select, "No X" column, + Add stage, card fields max 6, folded per view); filters and/or, nested groups, relation paths, type-specific operators; view menu (share with everyone/private, lock, move, copy link, set default admin-only, save as new, create view Table/Board, "view changed" clash); column order drag + search in view settings; bulk: select all N matching, set/clear/add/remove/replace, add field, >500 as job; undo keeps newer edits, "doesn't match this view" mark, comment count; create option from cell; object ⋯ menu (trash, duplicates, import/export every object).
Record page: stat strip (value, entered stage, next meeting, last activity); timeline of every value change with filter; details built from attributes (fold empty, add attribute, manage, locks); related sections per relationship (show more, add/move/create, remove Undo); list entries editable on record; duplicate banner + merge with…; panel with same tabs and ?record=; view-only/trashed/paused states.
Attributes: relationship setup (object, one/many each side, names); computed (lookup, rollup, formula); validation rules; more settings (description, API name, allow multiple, default country, decimals, defaults today+N / current user); change type step; attributes tab (rules column, search, archived section, option record counts, archive asks where records move); types interaction, member.
Objects: access per role/team/member (which records, field hide/lock, preview, impact); new object icon + 9 hues + suggested attributes; object ID, locked API name, archived object page; custom objects get full records (views, board, record page, panel, import, bulk).
Lists: fields of any type; list views; parent record columns; bulk edit; import into list; required list fields on add; list icon/hue/archive.
Differs: merge has no undo (Swap kept record); lists archive not delete; trash per object ⋯; new view starts private; sort builder drag up to 5; percent is number display; attribute editor modal; no email tab; panel ↑↓.

# Records vs competitors (Attio, HubSpot, Pipedrive, Salesforce, folk, Close, Twenty), 11 Nov
Person: several emails/phones with type + primary; socials; location + time zone; avatar from email; description; seniority/function; lifecycle stage + lead status; source auto + 3 detail fields; consent/marketing status; computed: last/first interaction, next meeting, interaction count, connection strength, strongest connection.
Company: several domains, logo from domain, description, categories; employee range, revenue, funding, founded; HQ + socials; parent/child; ICP fit; lifecycle; won revenue + open deals rollups; team (people at it).
Deal: pipeline (several); stage probability + override + weighted amount; currency per deal; line items/products (qty, price, discount → amount, MRR/ARR); date entered stage, time in stage; won/lost reason + date; next step, priority, type new/renewal, source, forecast category; deal age, days to close; contacts with roles; followers/deal team.
Lists: entry added by, time in stage, stage history; list computed fields.
Features: email/calendar sync auto-creating people/companies + interactions; enrichment from domain; relationship intelligence; several pipelines; rotting deals (idle limit per stage, red mark, filter, alert); forecast view by close month with weighted/committed/best-case + quota; stage history and won/lost reports; products catalogue; follow a record; sequences; AI fields; association labels/roles; leads + convert; consent management; share a record with users/teams.
Premium: zero entry from mailbox; strongest-connection chip; deal health on cards (rot badge, days in stage, weighted value) + forecast strip.
