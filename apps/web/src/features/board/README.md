# Board

A view of kind `board` (spec 0021): one column per option of a status or single select field, plus a "No <field>" column first, each column's cards in the view's sort order with its count. The view screen (`../views/ViewScreen.tsx`) shows it in place of the table, under the same bars and Toolbar, so filters, drafts and Save work on a board unchanged.

## Brief

- **Purpose**: see one object's records as a pipeline, a column per stage.
- **Main task**: see where every record stands and drag a card to its next column, live for everyone.
- **Leaves out**: Group by and Show empty columns in View settings, and the stuck badge (milestone 3). A column's "+" (members who may create, a grouping field they may write) opens the same create dialog as the top bar's New <record>, with that column's option set (the "No <field>" column's clears it), the field moved up beside the name.
- **Columns** (the CRM flow pass, 31 October 2026): "+ Add stage" (or "+ Add option" for a select) after the last column, for `schema.manage` on a grouping field they may write: the name typed and Enter make the option through `data.options.make`, the path a Select's Create uses, and the board gains its column when the attribute is read again; a refusal is said under the name, which stays. Any column folds into a strip (name and count) from its head and opens from the strip, kept per view in this browser (`collapsed.ts`, `crm.board.collapsed.<viewId>`). A card opens its record in the panel beside the board (`?record=`, AC-509), ↑ and ↓ stepping its column.
- **View settings** (22 October 2026): the view bar's one button opens the card's fields (the name first and locked, at most six shown) with Add attribute at its foot for `schema.manage`, which opens this screen's attribute dialog, so a board always has a way to add an attribute. Table or Board sits after it, the same height.

## States

Loading (the Board's skeleton columns after the loading delay, and three skeleton cards in a column whose call is still out), failed with Try again (from the call that failed, the columns already in kept), nothing to group by (with Add attribute for `schema.manage`), an archived grouping field, more than 50 options, no columns (a field with no options yet), an empty column ("No cards"), hidden empty columns, a filtered count past 10,000 ("10,000+"), read only with each card's lock, a refused drop, and live paused in the view bar.
