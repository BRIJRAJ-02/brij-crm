# Forms QA checks

The forms "bulletproof before release" set (5 November 2026), written ahead of the three forms lanes so it runs the
moment they merge: `wip/forms-fixes` (CRM filing, submissions, emails, closing, uploads, consent), `wip/forms-builder`
(After they send, steps, the question card, logic) and `wip/forms-guest` (the guest form, the live dialog, Share,
Analytics). Each check targets behaviour by role and label, not today's DOM. A check whose UI isn't built yet is
`fixme`, naming the lane that delivers it. A test marked **BUG** fails today on purpose: it is a real defect, left
red until it is fixed.

## Run it

```bash
# Unit and Postgres checks (need the local Postgres on 5433, as every package suite does)
pnpm --filter @crm/contracts exec vitest run src/forms/qa-bulletproof.test.ts
pnpm --filter @crm/emails exec vitest run src/templates/forms-qa.test.ts
pnpm --filter @crm/core exec vitest run src/forms/qa-bulletproof.test.ts

# Flows, against a running app (pnpm dev, or a preview: FLOW_BASE_URL=http://localhost:5700)
pnpm --filter @crm/web exec playwright test e2e/forms-qa-stress.flow.ts e2e/forms-qa-a11y.flow.ts \
  e2e/forms-qa-phone.flow.ts e2e/forms-qa-security.flow.ts --project=1280
# The phone file in WebKit too
FLOW_PHONE_BROWSER=webkit pnpm --filter @crm/web exec playwright test e2e/forms-qa-phone.flow.ts --project=1280
```

Each flow file makes one workspace in `beforeAll` and its tests borrow the owner's cookies (`forms-qa.ts`). Every
local visitor shares one address, so `send()` waits out the five sends a minute limit when the page says so; the
security file's rate limit test spends a whole minute on purpose and runs last.
