# apps/web

## Overview

The single page app behind login (React 19, Vite 8, TanStack Router), plus the small Cloudflare Worker that serves it and proxies `/api/*` to the API, so the browser only ever talks to one origin. Tagged `client` for `pnpm boundaries`, so it may never import server packages.

## Key files

| File | Owns |
|---|---|
| `src/main.tsx` | Creates the data layer and the router, and puts the data layer in router context |
| `src/routes/` | File based routes. Each route has a loader, a pending component and an error component |
| `src/routeTree.gen.ts` | Generated by the router plugin. Never edit it by hand |
| `src/features/<feature>/` | The screens for one feature |
| `worker/index.ts` | The edge Worker: static assets, plus the `/api/*` proxy with forwarded host, protocol and client IP |
| `wrangler.jsonc` | Assets, single page app fallback, `run_worker_first` for `/api/*`, `keep_vars` |
| `public/_headers` | Content Security Policy and caching (hashed assets immutable, everything else `no-cache`) |

## Commands

```bash
pnpm --filter @crm/web dev        # :5173, proxies /api to the api on :3000
pnpm --filter @crm/web build      # to dist/, with _headers inside
pnpm --filter @crm/web preview    # wrangler dev on :8787; copy .dev.vars.example to .dev.vars first
pnpm --filter @crm/web typecheck  # the app and the Worker (two tsconfigs)
```

## Conventions

- Screens get data only from the data layer in router context (`context.data`), usually through a route loader. Never `fetch`, and never import `@orpc/*` or `@crm/contracts` here. Types come through `@crm/data`. See `crm-frontend-state`.
- Lint refuses `className`, `style` and stylesheet imports anywhere in `src/`. If a screen needs a look the library doesn't have, add a variant in `packages/ui`.
- Every screen file opens with a three line brief comment: Purpose, Main task, Leaves out. See `crm-design-system`.
- UI comes only from the component library (`packages/ui`, arriving with #4), using tokens only. The current status page has no styles on purpose.
- A route's error component offers a retry that calls `router.invalidate()`, so it recovers without a page reload.
- Public URLs are baked in at build time as `VITE_*` variables. Turbo includes `VITE_*` in the build hash.

## Gotchas

- In `vite.config.ts`, the router plugin must come before the React plugin.
- The CSP in `public/_headers` allows only `'self'`. Adding Centrifugo, Sentry or PostHog means adding their origins there, or the browser blocks them.
- `API_ORIGIN_INTERNAL` is never in the repo: set it in the Cloudflare dashboard for production, with `--var` per preview, and in `.dev.vars` locally.
- The API's host address is public, so the forwarded headers this Worker sets can be faked by calling the API directly, until #57 Edge only API access lands.
